# name-format-change
Name Format Change

A beginner-friendly Python project that demonstrates how to change text format using Python string functions.

📌 Description

This program takes a user's name as input and:

Converts it to uppercase
Converts it to lowercase
Finds the length of the text

🧠 Concepts Used

User Input
String Functions
upper()
lower()
len()

💻 Code

name = input("enter your name: ")

print(name.upper())
print(name.lower())
print(len(name))
